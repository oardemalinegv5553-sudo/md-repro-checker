## MD 文献可复现性与可比性检查器

**具体目标。** 把方法段解析成结构化字段已有成熟工具，本项目立足于对文献方法段进行参数抽取后进行可复现性检查。产出检查器：读入方法段，输出四态结构化字段、一致性冲突、
敏感性归因与带来源标注的 GROMACS / LAMMPS / OpenMM 输入文件；并可成组
比较一批文献，判断各自报出的数值是否可比。

**核心价值。** 形成复现一篇 MD 需要的参数的显式知识资产：分层 schema
（18 字段分三级）+ 条件化敏感性规则。采用两层解耦：字段说明"是什么"，
归因说明"缺失会偏多少"。同一个恒温器缺失，与自由能无关，对热导率则
结论不可用。这是相对通用解析器的增量，也对应 Bohrium 的"AI4S 资产化"。

**可行性简析。** 关键路径是五段松耦合流水线，可独立交付；知识层为纯 YAML，依赖仅 pyyaml。目标缺陷类是静默失效：跑得完、不报错、数值偏，如 LAMMPS 漏写
`pair_modify mix` 即静默采用几何平均。主要风险：适用性判定
靠关键词，对离子液体、MOF、生物膜会失效；标注集仅 2 个版本，指标只够暴露
错误类型。验证方式：在人工标注集上分列三态宏 F1、取值准确率、规则 P/R/F1
与假阳性总数。
